# VIBES 产品概览

本文记录用户已确认的产品方向、当前 MVP 范围和设计参考；具体已实现功能以 [功能地图](features/README.md) 为准。旧站是参考，当前 MVP 是实现起点，不按旧站整站重建。

## 要做什么

**vibes.college is the campus for the AI economy, where people and agents learn, meet, trade, and build together.**

VIBES 是 AI 经济的校园，让人和 Agent 在这里认识 AI、认识彼此、交易成果，并一起创造。

Explore 围绕两条线组织内容：**Learn what’s shaping AI. Learn what’s changed by AI.** 谁或什么改变、影响、创造了 AI，以及 AI 改变、影响、创造了什么。长期内容包括 AI 知识、vibe coding、电影、音乐、书籍、生意、人物、播客、动画、论文、帖子、新闻、创业、就业和需求。

长期探索路径：发现 → 兴趣 → 搜索 → 深挖 → 收藏 → 决策 → 行动。该路径是产品方向，不意味着当前 MVP 已包含收藏、交易或协作。

## 第一版与本次实现

第一版只做 Explore，不做公众或 Agent 编辑。当前已有首页、文件维护的 24 条内容、搜索和分类，继续保留。本次只调整分类栏和详情体验，不扩展其他板块。

- 首页：保留现有卡片与整体视觉，顶部分类改为小字号英文，压缩留白。
- 详情首屏：从上到下是原网站链接、preview、标题、介绍、每条内容各自的信息标签。标签优先展示帮助用户快速判断的信息；可导航的信息链接到筛选列表或对应正文。
- 详情切换：在详情内左右滑动切换作品，不必退回首页；桌面提供按钮和方向键。以现有目录顺序为默认顺序，首尾不循环。
- 详情正文：向下滚动或点极简箭头进入正文；大标题默认折叠，先看全局，再逐段展开，保留正文表格、列表和来源。
- 手机优先：三张用户截图均为手机设计参考；电脑端沿用内容顺序，适配阅读宽度和操作方式。
- 继续复用当前内容和预览组件，不因为旧站截图而新增聊天、点赞、评论、登录、收藏、公众投稿、积分或支付。
- 搜索与分类继续使用当前实现；完整 Are.na connection、公众编辑和协作属于长期方向，不在本次实现中。

## 需求工作方式

今后新增需求先通过最多 3 个问题一轮，确认谁用、核心路径、第一版不做什么和关键边界，再写文档或实现；不主动增加功能。用户已经明确的决定不重复询问。本次用户已明确要求先记录概览、再实现以上界面调整。
