# 功能名：使用本地助手

## 一句话说明

访客把自己电脑上的Paseo连接到Vibes，在阅读作品时与自己的Agent交流，或打开已有项目继续动手；会话和文件操作由Paseo原生工作台提供。

## 用户操作路径

1. 在`/zh/`、`/en/`或作品详情点右下角透明背景的吉祥物图案入口；按钮的可访问名称为“本地助手”，英文为“Local assistant”。第一次点击立即显示安装与连接说明，并开始准备工作台；没有点击时不下载Paseo资源或连接电脑。无JavaScript可继续阅读，助手入口不启用。
2. 在要运行Agent的电脑上，按说明打开Paseo官方桌面App下载页或CLI安装说明。桌面App打开后自动启动服务；电脑需要保持开机、运行Paseo。手机也能使用网页，但仍依赖这台电脑。
3. 在电脑上安装并登录Codex或其他受支持的Agent。Paseo不提供模型账号，使用沿用用户自己的账号和配置。桌面App从Settings → 当前host → Pair Device取得配对信息；CLI按启动提示启用中继并显示配对二维码。
4. 点“已安装，去连接”，在Paseo原生界面完成配对并等到电脑在线。已有配对由Paseo恢复；“工作台已准备”仅表示界面可用，不表示电脑已连接或模型可用。
5. 首次进入且没有已选工作区时，在连接的电脑逐级准备`~/Vibes/Chat`。已有同名目录会保留，同名文件或权限错误会显示原因，可重试或选择其他项目。Vibes不要求Codex或ChatGPT订阅，也不自动选择Agent和模型；没有原生偏好时，请从模型入口选择本机可用的Agent与模型。这里只准备草稿，点击发送后才创建Agent；已有旧目录或工作区继续恢复，不自动迁移。
6. 小窗只显示对话，白色顶部一行提供新对话、展开和收起三个按钮。新对话沿用当前工作区与Paseo原生偏好；没有明确选择时保留原生选择入口，不填入Codex/Luna，不覆盖用户选择或主动清空。要选择已有项目或历史会话时先展开，再从左侧菜单进入原生入口；“新建工作区”进入原生创建页面。已有配置、草稿和附件沿用Paseo保存。
7. 输入问题并发送，查看逐步回复、推理与工具卡；需要批准时在原生审批入口决定，运行中可点停止。全屏保留原生会话、文件与终端切换；窄屏使用原本的会话切换入口，不额外放置“新建Agent/Terminal”加号菜单。错误、断线和恢复状态由Paseo显示。
8. 点“专注交流”展开同一工作台，点“返回边读边聊”回到小窗；顶部减号在两种尺寸下都直接收起。返回小窗时显示当前工作区的会话或草稿，文件和终端标签仍保留。桌面宽屏在文章旁显示，较窄屏和手机在底部保留阅读空间；小窗时文章可滚动，全屏时固定后方页面，返回后恢复阅读位置。收起不会停止电脑上的任务，也不等于断开或忘记设备。

文章提示气泡显示在吉祥物上方，展开的章节目录让出入口的操作空间。按钮之间及旁边的空白不拦截后方页面的点击或翻页手势。

助手中的聊天、侧栏和菜单统一使用原生浅色主题，从首次打开到恢复已保存设置都保持白色界面；系统深色、以前保存的深色或插件主题不会覆盖它。这项显示规则不自动改写独立Paseo的主题偏好。

手机输入框至少使用16px字号，小窗按可见视口适应键盘和视口移动；收起或切换尺寸会收回输入焦点，保留手动缩放。真实iPhone Safari的键盘、缩放和滚动仍需真机验收，设备模拟不能代替该结论。

连接设置也保留手工添加直接连接或自建中继地址的入口；能否连通仍取决于浏览器对安全连接和本地网络访问的要求，以及电脑上Paseo的来源校验。页面允许相应连接类型不等于已通过所有网络环境的验收。

### 用英语听写

电脑端需启用听写并准备官方默认的本地英语模型。小窗只有输入框有文字才显示文字发送；空输入始终显示麦克风，不受当前焦点或曾经点击影响，清空文字立即恢复麦克风，仅有文章引用或其他附件也保留麦克风。全屏与全屏的新建工作区页面保留原生输入控件。点击麦克风后按浏览器提示授权并开始录音，不会因为打开助手而录音或弹出键盘。

听写能力取决于当前工作区连接的主机。同一网页中，一个主机关闭听写、另一个开启时，麦克风会分别禁用和可用；手机与电脑浏览器的配对分别保存。按钮灰色时先核对当前主机是否在线并启用听写，不能仅凭工作区名称判断连接相同。

录音时音频经Paseo连接送到电脑的听写服务。点发送结束录音，等待最终转写，再通过原生发送或排队操作提交文字并携带原有引用和附件。取消会放弃当前录音，等麦克风恢复后即可重新录音，不必等待旧连接请求的确认；转写失败可重试或丢弃，消息提交失败按原生反馈继续处理，不能把转写完成或按钮恢复麦克风当作消息已经发送。

小窗中停止Agent、关闭模型选择或拖入附件不会自动把焦点拉回输入框；仍可主动点击输入框或使用明确的文字输入快捷键。

小窗和全屏均隐藏Realtime实时语音入口，仅保留听写，不改电脑端已有语音配置。当前听写范围是官方默认本地英语模型；中文、云端转写、实时语音对话和语音播报未纳入这条路径的验收，服务与数据边界见[本地助手系统说明](../system/local-assistant.md#听写与音频边界)。

### 带着文章提问

进入作品详情时，吉祥物上方显示“和Agent聊这篇”说话气泡，约5秒后消失。鼠标移到入口或用键盘聚焦时可再次显示；键盘操作期间保持可见。手机普通打开再收起助手后重新提示5秒，切到另一篇文章也会重新提示。普通点吉祥物仍只打开助手。

点气泡会在当前草稿附上一个可删除的文章引用，同时保留输入文字和普通附件。引用只包含公开标题、作品标识和标准网址，不含正文、摘要、本地路径或浏览器信息；不会自动打开原站或代替用户发送消息。更换引用只替换已有的Vibes文章引用。

点引用上的移除按钮可删掉它；缩放、收起重开、切换文章或刷新不会把已删引用重新附上。再次明确点击“和Agent聊这篇”才产生新的引用请求。暂时附加失败会保留草稿并提供重试。提交时以原生文字附件发送，标为不可信页面资料，不作为指令或操作授权。无公开HTTPS标准网址的本地页面不显示文章入口。

### 打开Agent产出的文件

窄屏全屏时，从左侧菜单History/Plan下方点Files，菜单关闭并打开占满工作台内容区域的原生文件浏览面板；文件树不在左菜单里展开。点文件后进入对应的原生文件标签，文件浏览面板自动关闭；也可点关闭回到会话。桌面宽屏继续使用原生右侧文件栏。

点击原生消息中的文件链接，助手会从小窗自动展开并保留目标文件标签，进入工作区文件窗口查看文本、图片、Markdown或HTML；带行号的文本链接定位到对应行。在小窗主动打开终端也会展开，返回小窗时恢复最近会话，文件和终端标签仍保留。可编辑文本使用原生编辑器，修改后自动保存到电脑。文件由连接电脑提供，HTML的隔离和下载边界见[接口与服务](../system/interfaces.md)。PDF/Office没有新增专用预览，二进制、过大文件和不可读文件使用原生反馈；通用下载受连接类型限制，纯中继连接不等同直接连接下载。

输入区可通过“添加附件 → 添加图片”选择本地图片，点缩略图打开原生灯箱；手机轻点大图显示控制按钮，再点关闭返回草稿。选择图片不会自动发送消息，移除按钮可从草稿中删除附件。

### 中断后继续

资源下载失败时安装说明仍可读，检查网络后点“重试加载”；初始化失败按提示刷新。工作台已打开后，站内切页、语言切换、小窗与全屏切换沿用同一原生界面。离线、电脑睡眠或网页转入后台后，返回时查看原生连接与会话状态，恢复连接后再继续；不要把加载完成提示当作Agent执行成功。

需要断开或忘记电脑时使用Paseo原生连接设置。忘记、清除浏览器存储或换浏览器后可能需要重新配对；收起助手只隐藏界面。任务执行权限来自电脑上的Agent配置，`~/Vibes/Chat`默认目录不构成文件访问沙箱。

## 验收标准

- [ ] 普通浏览不请求Paseo；首次点击立即出现安装说明，慢网和资源失败仍能查看、重试。
- [ ] 真实电脑完成首次配对和再次连接，初始预设能发送并得到真实Agent回复，原生项目入口能在选定项目执行并产生可查看文件。
- [ ] 缺模型、目录错误、配对失败和掉线显示真实状态，并提供可继续的入口。
- [ ] 文章引用仅由明确入口添加，可删除且不覆盖草稿；再次打开或切页不自动复添或发送。
- [ ] 小窗、全屏、收起重开、站内切页保留会话与输入；收起不取消运行中的任务。
- [ ] 两种尺寸各只有一行工具栏；小窗保留当前会话，窄屏全屏可进入新建工作区及原生全屏文件面板，宽屏右侧文件栏可用。
- [ ] 麦克风权限、录音、取消、最终转写、发送或排队及失败重试符合实际结果，不重复提交，不在小窗自动弹出键盘。
- [ ] 原生工具、审批、停止、历史与文件路径在实际连接上可操作；HTML预览遵守隔离边界。
- [ ] 桌面与手机的阅读、键盘输入、选择文字和滚动可用；长时负载及iPhone真机后台恢复通过专项验收。

## 已知问题 / 待办

- 首次打开需要下载完整Paseo应用，耗时取决于网络和设备；安装说明先显示，工作台大小不代表可交互速度。
- Agent必须在用户电脑上可用；原生会话和文件能力仍受模型、连接类型与电脑权限约束。
- 当前测试版WebKit的私密上下文无法把图片Blob/File写入IndexedDB，原生图片附件可能无法加入草稿；隔离的普通持久profile可写入。建议上传图片使用普通窗口，真实Safari与iPhone私密模式尚未验证。
- 当前保留精简页头，尚未接回原生工作区专属菜单、Scripts和Git网页快捷入口；原生命令中心、Changes及文本编辑器仍保留。设置中的插件入口仍在，但插件执行依赖eval，主页面未开放，因此插件尚不能运行。这些缺口已记录，后续接入。外部编辑器启动依赖官方桌面桥，不是普通浏览器能力。
- 原生Browser标签页和remote SSH属于官方桌面端专属能力，不属于Web接入承诺；听写需电脑端正确配置服务，并由浏览器用户授权麦克风。
- 长时固定负载、真实iPhone键盘/旋转/锁屏和完整辅助技术路径保留后续专项验收，不把模拟浏览器通过写成真机结论。
