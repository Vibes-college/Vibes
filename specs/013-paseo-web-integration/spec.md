# Paseo原生助手：安装、连接与持续使用

## 已确认的目的与接入方案

通过多轮具体场景确认用途后，用户选择直接采用旧项目和旧PR验证过的接入方式，并授权接入时作有明确收益的改进，不要求完整复制旧代码。采用完整官方Web直接挂载及薄宿主边界；下列US/FR保留原始完整目标，SC数值是测量前固定的工程验收目标；本规格的complete仅表示下方用户确认的快速收尾范围已完成。完整目标中延期的功能与专项验收保留未完成状态，后续另立修订规格；有效范围和证据见plan与tasks。

已确认：建立新分支和Draft PR，吸收并保留过去经验，优先复用官方Web协调能力，按用户感知分阶段评价，不先为减包而裁剪。基础能力至少包括与Agent对话、执行任务、返回结果和查看相关产出文件。

首次默认目录为电脑上的`~/Vibes/Chat`。Vibes不自动选择Agent、provider、模型或思考强度，也不要求安装Codex或订阅ChatGPT；无已存选择的新草稿由用户通过Paseo原生入口选择可用配置，已有原生偏好、项目、会话和草稿继续恢复。目录准备不等待某个provider或模型就绪，已有旧目录/工作区不搬迁、不覆盖。界面不显示Chat/Build模式，不维护两套项目选择状态；默认目录不是权限沙箱。

产出范围已确认：直接复用所选Paseo原生能力，它能查看什么就保留什么；不新增格式预览器、下载服务或自建产出系统。

已有项目用途保留：用户按原生项目入口选择电脑里的项目或文件夹，由Agent继续处理；首次默认预设不能覆盖这些选择。旧稿中的Chat/Build分别指默认预设与已有项目两种用途，不再作为可见模式或独立工作台。

Standalone含义已确认：Paseo作为独立模块接入Vibes，便于维护；不要求额外建设独立使用页面。它是接入与维护边界，不是第三种用户界面。

界面用途已确认：compact在手机与电脑都只呈现当前工作区的聊天，full呈现完整原生工作台。缩小时聚焦该工作区最近会话或原生草稿，保留已经打开的文件、终端与其他标签；展开后仍可回到它们。已在compact主动点击消息文件链接或打开终端时自动展开full并保留目标标签，不能立即强制拉回聊天。这是同一工作区内的呈现变化，不另建聊天历史或恢复体系。

文章上下文已确认：参考旧项目，从文章入口打开Agent时，在聊天输入框自动附带可删除的文章引用；用户可以先删除再发送，不另造手动附带流程。旧源码核实引用只含页面类型、路径、作品身份与标题/链接，不含全文或摘要；外观类似链接的引用标记本身不等于已读正文。

首次使用沿用户最初明确的安装App/CLI→连接路径，在阅读引导时预加载；已安装用户直接连接。核心用途与直接挂载方案已收敛；安装命令、兼容版本和技术边界由Agent核查，不把实现细节变成新一轮产品问卷。复用经验证的接入边界，改进职责、首次准备与界面；不整批带入旧实验。

### 本轮已确认的布局与听写

- compact在手机与电脑使用单条44px白色头部，只保留新会话、展开和收起；不显示菜单、Chat/Build或原生标签栏，正文是当前工作区聊天。新会话仍由原生草稿与提交路径创建。
- full使用统一头部，提供菜单、缩回compact和收起，保留原生会话/标签切换；窄屏不额外放置Agent/Terminal新标签加号菜单。“新建工作区”可从左侧菜单进入官方创建页面。窄屏仅把Files入口放在历史/计划之后，点击关闭左菜单并打开原生全宽高文件浏览面板，不在菜单内展开树；点文件打开原生文件标签并关闭面板。宽屏保留原生右侧文件栏。文件、终端、工具详情与审批能力不能随compact隐藏而被删除。
- 嵌入助手的原生界面统一使用浅色主题，从首次渲染到恢复已保存设置均保持白色界面；系统深色、已存深色或插件主题不覆盖，不自动改写独立Paseo的主题偏好。
- 右下角入口使用用户提供的透明PNG吉祥物；文章入口表现为吉祥物上方的说话气泡，约5秒后隐藏。鼠标悬停或键盘聚焦可重新显示，键盘操作期间不隐藏；手机打开再收起助手或切换文章后重新提示。普通点吉祥物不附加文章，点气泡继续原生文章引用路径。
- 修复iPhone Safari iOS26输入时自动放大、compact在软键盘出现后的定位，以及full状态向背景文章透传点击/滚动的问题；compact仍允许操作可见文章，退出full恢复原阅读位置。保留用户手动缩放，模拟设备结果和真实iPhone结果分开。
- 本轮只接官方默认local英语听写；compact和full都隐藏Realtime实时语音入口，仅保留听写，不改电脑端已有语音配置。不增加中文识别、云端STT、实时voice或TTS。麦克风必须由用户主动点击后才开始录音，能力不可用或权限被拒绝时保留真实提示和文字输入。
- compact仅在输入框有文字时显示文字发送按钮；空输入始终显示麦克风，不受当前焦点或曾经点击输入框影响，清空文字立即恢复麦克风，仅有文章引用或其他附件也保留麦克风。录音时的发送按钮继续用于结束录音、等待识别，再沿原生发送路径提交并携带附件。按钮呈现不代表消息发送成功。保留原生取消、转写、失败重试/丢弃与草稿恢复；结束录音、识别或发送成功、停止Agent、关闭模型选择和拖入附件均不主动重新聚焦输入，显式文字输入快捷键保留。

full及其新建工作区表单保留原生输入控件与空内容创建行为，不把compact主按钮规则扩展到full。听写是否可用由当前工作区连接的主机能力决定，不因为切换工作区而替用户更改主机配置。

用户于2026-09-11确认快速收尾：保留现有预览的布局与能力，仅调整默认目录和取消Codex/Luna预设；宿主漏接的工作区菜单、Scripts、Git快捷入口及插件兼容只记录限制，后续接入。完整恢复矩阵、官方性能对照、60分钟负载和iPhone真机专项移入后续验收范围，明确未测。本PR合并仍要求当前范围的真实基本使用、必要verify/budget、同SHA预览及独立审查，不以缩小范围伪造原验收通过。

## 用户与核心路径

面向在Explore发现作品、希望通过自己电脑上的Agent讨论或动手的普通访客。Vibes提供作品入口、公开上下文和轻量接入外壳；Paseo提供完整聊天工作台及其连接、会话与操作协调。沿用Explore现有页面与阅读体验。

- US1（P1）首次使用：点击助手立即看到安装与连接引导，前往电脑安装官方App或CLI、准备可用Agent，再完成配对。阅读引导期间后台准备助手；已安装用户可直接连接。任一步失败保留当前步骤、说明与重试入口。
- US2（P1）连接后做事：首次默认目录`~/Vibes/Chat`已准备，用户在原生入口选择本机可用的Agent与模型后输入；已有偏好继续恢复；需要处理已有项目时按原生方式选择项目/文件夹，后续保留当前选择。compact可打字或主动启动本地英语听写；由原生会话完成对话与执行、返回结果并打开相关产出，保留工具与审批、停止。compact让文章详情保持可读可操作，full可进入文件、终端与其他原生标签；从文章打开时，输入框自动带可删除的文章引用。
- US3（P1）继续浏览再回来：收起助手后继续搜索或阅读，切作品、语言、历史返回后重开，回到原会话、草稿与阅读位置。刷新、离线重连及从浏览器后台返回时，恢复结果可辨认，未确认的操作不会被盲目重发。
- US4（P1）持续使用：聊天、长记录滚动、工具操作和反复开合保持跟手；助手收起后Explore仍顺畅。维护者能依据分阶段证据定位问题，而非以包体大小代替体验判断。

各故事独立验收：US1完成未安装/已安装/失败重试路径；US2完成真实会话及拒绝/允许审批；US3覆盖在途操作与草稿的恢复；US4按同设备、同输入的对照结果验收。先完成接入与正确性，再针对实际退化优化。

## 功能要求与验收

- FR001：用户首次主动点击前，不下载、初始化Paseo专用资源或探测电脑；Explore的搜索、阅读和媒体行为保持现状。
- FR002：点击即展示轻量外壳和清楚的当前状态；安装、准备Agent、配对和可聊天是不同步骤。预加载与用户阅读引导并行，不固定等待几十秒，不伪造安装完成或可操作状态。
- FR003：已安装或已配对用户直接进入连接/恢复路径；缓存失效、慢网、离线、下载失败、加载中收起与重试均有明确结果。预加载仅准备网页资源，不代替用户配对或启动远端任务。
- FR004：采用固定版本的Paseo Web完整应用协调能力。探测、连接所有权、重连、过期连接、订阅恢复、历史补齐、重复与迟到事件和在途操作核对由同一原生运行体系负责；Vibes不再维护第二套连接或会话真相。
- FR005：compact/full按上方已确认布局呈现同一原生工作台。compact只有单条44px白色头部及聊天，无菜单或标签栏；full保留原生会话/标签切换，窄屏不加Agent/Terminal新标签菜单。左菜单的新建工作区可进入官方页面，Files入口打开原生全宽高文件浏览面板并关闭左菜单，点文件进入原生标签并收起面板；宽屏用原生右栏。compact显示时文章详情仍可阅读、滚动和操作，聊天输入不误触文章导航；full阻止背景文章接收点击或滚动。保留原生文件、终端、预览、工具详情与审批，缩小只隐藏相应呈现，不删除能力或状态，不新增独立使用入口。
- FR006：默认目录为首次工作区预设：配对后自动准备`~/Vibes/Chat`，无需先浏览目录或记路径；不自动选择Agent/provider、模型、模式或强度，不以Codex/Luna为前提。已有原生偏好与选择继续恢复，无偏好时保留原生选择入口。后续沿原生当前项目，不迁移旧预设、不覆盖已有目录内容、草稿或用户主动清空。Paseo正常执行能力与权限规则保留；初始化不得加载整个目录树，默认目录不等于权限沙箱。
- FR007：compact/full切换保留当前工作目录、模型、会话/草稿与聊天位置；compact聚焦当前工作区最近会话或草稿，full保留文件、终端及原生标签状态，不新建连接、工作区或替代历史。手机不因尺寸切换或听写结束强行聚焦、弹出键盘，用户仍可主动点文本框输入。full返回compact或收起后文章仍在原阅读位置；手机面板随实际可见视口和键盘定位，不压成两个不可用的并排区域、不触发输入自动放大，也不禁用用户手动缩放。Standalone按独立模块边界验收，不新增独立页面或跨标签共享需求。
- FR008：从文章入口打开Agent时，在原生输入框自动附可删文章引用，即使还没输入问题也附带；随用户提交草稿发送，不单独自动发送。保留原有草稿及编辑能力；删除后不因重绘、收起/展开或恢复加回。只切换文章不替换已有草稿引用；用户再次明确从文章打开时才产生新引用请求。保留旧页面类型、路径、作品身份、标题/链接的少量标识，链接按当前Vibes公开地址适配；不附全文/摘要，不增加正文抓取服务。引用是普通非可信资料，不提升为系统指令，不发送私有目录、配对信息或完整阅读历史。
- FR009：真实模型、会话、流式消息、工具状态、审批允许/拒绝和停止走原生操作路径。compact本地英语听写遵循上方主按钮规则，复用原生录音、取消、识别、发送及失败恢复；识别完成不等于发送成功，失败保留未发送内容和重试/丢弃入口，不主动重新弹出键盘。恢复或结果未知时区分已有记录与已确认状态，不静默重发发送、审批、停止或新建操作；原生行为不足时记录缺口，不重写客户端或启用实时voice/TTS补洞。
- FR010：收起只改变展示与必要的活动信号，不取消任务、不忘记设备。保留必要连接及状态更新，暂停无用显示工作；恢复显示后由原生机制核对。仅设置CSS隐藏不能作为后台成本通过证据。
- FR011：站内导航、重开和浏览器生命周期不创建重复根、连接、监听器或提交。当前会话、未发送草稿与位置在支持的恢复路径保留；存储被清除或浏览器主动丢弃数据时明确说明限制，不能显示虚假的恢复成功。
- FR012：断开、忘记设备和收起含义清楚。主动断开不被前台事件自动连回；忘记清除该设备的配对材料及约定本地缓存，不影响其他设备，不删除电脑文件或声称远端任务被终止。
- FR013：配对使用官方连接机制；浏览器配对材料遵循原生存储边界，不进入Git、日志、分析或公开URL。生产环境的连接、嵌入、插件和资源限制必须实测，禁止用开发服务器成功代替上线兼容性。
- FR014：图表、富文本、语法、多语言与图标先保留原生能力；只按普通用户路径简化可见入口。出现实测退化后再决定是否拆包、减少渲染或限制资源，并重新验证受影响行为。
- FR015：安装引导覆盖实际支持的电脑系统、官方安装入口、Agent准备及配对完成标志；手机明确需要一台运行Paseo的电脑。上游版本不兼容时提供实际可用的升级指引，不凭旧版本测试声称全部App/CLI可用。
- FR016：目录准备独立于provider/model列表；模型和Agent可用性由原生选择入口依据已配对电脑的真实配置展示，不显示虚假可用状态或静默选择另一种收费/权限配置。目录无权限、同名文件或创建失败给重试及原生项目入口；单窗口重复点击、目录已存在、网络中断和刷新恢复先核对已有结果，不重复创建工作区/会话或覆盖产出。跨标签并发沿原生非原子边界说明，不承诺协议未提供的全局恰好一次。
- FR017：用户能从对话结果进入相关产出，完整保留所选Paseo版本原生的相关打开与查看路径；不能以原生文件功能属于“高级能力”为由裁掉。不新增格式预览、下载服务或网页运行平台；不支持的格式和连接方式沿用真实原生边界并说明限制，不能把源码文本当作可运行网页验收。接入导致原本可用的文件预览失效属于回归，必须解决或明确报告。
- FR018：保留原生项目入口供用户按需选择已有项目或文件夹，继续会话与执行能力。首次默认预设不覆盖已有项目的目录、模型或设置；compact/full不改变项目归属，不向另一项目发送草稿或启动任务。文件、终端、Changes和命令中心等已有原生能力继续保留；漏接的页头快捷入口不能笼统称为Git或编辑能力缺失。

SC012（阅读与专注）：在文章详情打开compact，能交替滚动文章、输入和查看回复，双方交互不串扰；同一工作区切full继续交流或操作原生文件/终端，切回后文章位置、会话、草稿和聊天位置不丢失，未创建额外连接/会话。手机和电脑分别核对单头部、可见控件、原生标签与文件区域位置；full不穿透背景，compact键盘出现后输入与主按钮仍在可见视口内。iPhone Safari iOS26输入缩放与真实键盘结果单列，未测不能以模拟通过代替。

SC013（可删文章引用）：从文章打开后输入框出现对应引用，原草稿保留；删除后发送不包含该引用。收起/展开、compact/full及连接恢复不恢复已删除引用；保留引用发送时，核对实际资料与当前明确引用的文章一致，原生发送/失败路径继续生效。
