# 正文分章表情评价

## 用户与路径

访客阅读正文，在每个主要章节标题（现有h2，不包括封面h1与章内h3）文字右上方看到小型表情入口，选择表情表达对该节的感受；自己的浏览器刷新后保留。

## 要求与验收

- FR-001：入口紧挨标题文字右上方，图标约14px、小于18–20px标题；提供不遮挡文字的点击区域，常态低对比但可发现，触屏无需hover。
- FR-002：参考Rare UI Emoji Reaction：弹性展开五个表情、依次出现、hover轻微抬升；每次选择发射5个表情，错开250ms，约1.4–1.8秒上飘、横向漂移、缩放、摆动、模糊和渐隐；长按约550ms重复。
- FR-003：第一章与贴近视口顶部的触发器，工具条和飞行动画朝下；其他位置按空间选择方向，工具条与动画不使320px页面横向溢出。弹层不被正文裁切，不推动段落布局。
- FR-004：键盘、点外部/Escape关闭、触摸选择与按住后拖选可用；关闭、取消、换页和后台状态清理长按与粒子，减少动态偏好只更新选择。全页同时最多一个工具条，粒子有上限。
- FR-005：按作品路径和稳定标题id保存单个表情，不发送服务器、不显示假公共计数；存储不可用或坏值不阻断评价。只在自身浏览器保存，清除站点数据后失效。
- FR-006：保持Safari正文底部正常滚动修复、进度目录与相邻导航；点击表情不误触横滑切换。未启用JS时正文可读，评价入口隐藏。
- SC-001：三端自动化覆盖保存/恢复、章节独立、弹层边界、顶部下飘、减少动态和关闭清理；完整verify/budget必过。
- SC-002：内置浏览器与原版对比工具条与粒子视觉，Cloudflare预览交付。性能分开记录首屏、首次评价加载与动画帧，超出既有预算不得静默放宽。

## 不做与边界

仅当前浏览器本地评价，不做公开计数、身份、后端接口、跨设备同步或内容编辑。沿用Astro/TypeScript，不新增npm依赖。标题结构与内容保持原样；用户已允许小幅放宽预算；全站全部脚本（包含懒加载块）gzip上限调整为19,000字节，首页与原有交互源码预算不变。整页加载完成、正文可见1.5秒后利用空闲时间预加载，省流量模式仅点击加载；提前点击立即加载。自动化核对封面无请求、正文空闲准备与省流量分支，记录初始脚本增量。
