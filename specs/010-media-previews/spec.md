# 作品的多媒体封面与渐进体验

## 用户与核心路径

- US1（P1）：维护者为作品整理素材、出处和分语言说明，分别安排首页与详情展示；生成尺寸、时长、封面、预览片段及适合的版本，校验错误直接定位作品及字段。没有素材的旧作品保留现有抽象封面。
- US2（P1）：访客浏览或搜索作品，先看到有尺寸的真实封面；可见停留后观看静音预览，主动点击试听音频，点击独立的作品入口进入详情。手机快速划过时不启动大量媒体。
- US3（P1）：访客在详情切换、放大图片，播放完整视频或音频，查看字幕、文字稿与章节；暂停循环特效，主动启动及退出交互演示或数据图表。播放和拖动不触发文章换篇或正文切页。
- US4（P1）：访客切语言、切作品、搜索、历史返回或切到后台时，旧媒体停止并释放，失败仍有静态内容与原作入口；维护者能用代表内容验证六类路径。

## 功能要求与验收

- FR001：作品类型独立于展示形式。共享资料增加可选素材清单和首页/详情展示安排；标题、替代文字、图注、字幕和说明跟随语言版本，不改稳定ID、原文/译文发布规则。
- FR002：素材记录身份、类型、来源、出处/署名、适用尺寸、时长、格式及按需变体；引用必须存在且类型正确、无重复身份或循环替代关系。程序拒绝非法地址、任意脚本和未登记的演示。
- FR003：图片支持真实素材、响应式版本、主体焦点、图注及替代文字；首页可裁切、详情完整显示，图库支持顺序切换和放大，按需加载相邻图。
- FR004：视频区分静态封面、独立首页短预览和完整视频；支持文件来源或明确支持的平台播放器、字幕和章节。静音预览不下载完整版；详情提供声音、进度、暂停与全屏能力。
- FR005：音频支持封面、完整时长、独立试听、真实预计算波形、可选文字稿、同步文字和章节。未经操作不自动出声，缺失文字不编造。
- FR006：循环特效支持短视频与动画图片；循环视频暂停停在当前帧，动画图片停止时切静态封面、重新开始可重播。详情可暂停，减少动态偏好下不自动启动。
- FR007：交互作品首页使用截图或操作短片，详情点击启动已登记组件或允许的外部嵌入；有操作提示、退出和原站后备入口，不承诺任意网址都能嵌入。
- FR008：论文/数据作品展示真实图表、来源定位、关键结果及成立条件；有数据时支持列、单位、图表映射、系列或范围选择、数据日期；无数据不生成虚构交互结果，不默认抓取实时数据。
- FR009：首页、搜索结果和详情使用统一素材解释及播放管理；可见停留后启动，手机最多1个、桌面最多2个自动动态预览；播放有声内容暂停其他播放器，手动暂停不被自动恢复覆盖。
- FR010：滚出视野、详情进入正文、离开页面、切语言、搜索替换、后台时暂停或释放；禁止迟到请求和播放承诺重新激活已离开的媒体。再次显示遵守用户暂停及自动播放规则。
- FR011：按钮、播放器和演示不嵌套在导航链接里；点击播放不进入详情，操作图库/滑块/演示不误切篇；键盘操作、焦点恢复及原生移动端手势保持有效。
- FR012：封面预先占位；失败或自动播放拒绝保留可读封面、重试/播放及原作入口；无JS仍能阅读、查看静态图和通过链接打开源文件/作品。
- FR013：素材处理复用已安装工具，显式输入输出、不得覆盖原素材；图片生成尺寸版本，视频生成静音短片和海报，音频生成试听和波形；输出确定的机器可读清单。构建不依赖外部网络或实时转码。
- FR014：新增来源采用精确允许列表和最小嵌入权限；可缓存的文件与需播放器服务的资源分开，不提前创建付费存储/转码服务或把秘密交给浏览器。
- FR015：提供可长期体验的六类代表内容及来源说明；自制实验明确为Vibes演示，不冒充第三方作品或论文实验结果。至少一种媒体例子在中文/英文、搜索与连续导航中验证。用户补充要求真实作品入库：YouTube完整视频配原创导读、Spotify官方音乐、可玩的游戏、论文项目、博客、X帖子，以及yaoda.work中可核对的Spine骨骼动画作品。原创参数实验仅保留为草稿测试素材，不作为推荐作品充数；登记具体外部嵌入来源，不接受任意URL。
- FR016：播放/暂停采用封面右下角小型半透明圆形图标；详情预览下不显示说明、署名小字、章节或额外留白，大标题紧接封面。章节/文字稿移入封面内按需展开的操作菜单，署名许可保留正文与素材资料；首页音频播放时波形运动，暂停停止，减少动态时静态。
- SC001：六类内容均可完成首页到详情的独立操作路径；图库、视频/音频、循环、演示、图表成功及失败测试均通过。
- SC002：320px宽度无整页横向溢出；媒体操作不改变当前作品/详情页状态；原有搜索、阅读、语言切换及历史返回回归通过。
- SC003：普通无媒体页面不请求媒体资产；完整音频、完整版视频、嵌入和交互模块在主动操作前不请求；自动播放数量不超过FR009，离屏/后台不继续播放。
- SC004：保留现有脚本、首页与图片预算；新增预览文件和数据设独立硬预算并覆盖边界测试，不通过提高现有门槛掩盖回归。
- SC005：记录真实环境的页面出现、动态首帧和点击后开播时间；区分首次与缓存访问，WebKit模拟与iPhone Safari真机分开。没有真机结果不得声明Safari真机验收通过。
- SC006：完整verify与budget通过，内置浏览器完成真实操作审阅，必要功能/系统文档与代码同一PR；实现、待合并和未部署分别报告。

## 明确不做

不改首页整体布局和产品导航，不开放投稿、编辑、CMS或用户账号，不引入跨页后台音乐播放器，不默认部署R2/Stream付费服务，不执行第三方任意脚本，不绕过原站嵌入限制，不把短片等同交互作品，不自动迁移全部旧作品。

## 端差异

无JS可见静态封面与原作链接，增强交互依赖JS；桌面鼠标/键盘、手机触摸分别验证。浏览器省流量信号只作为可用时的提示，不假设Safari提供此信号；减少动态设置和自动播放拒绝都有静态回退。真机缺席不阻止可验证的实现，但保留真机待测项。

## 行数预算

不设规格目录篇幅上限。research记录媒体生命周期、素材编码、嵌入与预算取舍；不另建data-model/contracts/quickstart，当前结构说明随docs/system/content-model.md维护。

## PR工作台与经验复核

按用户确认的三个阶段推进，同一Draft PR维护清单、证据、阻塞和预览。落实docs/LESSONS.md中的异步返回、页面切换和iOS误翻页经验：媒体异步操作有生命周期取消，交互区排除切页手势，不引入滚动吸附。合并仍需用户明确指令，阶段预览不提升生产。
