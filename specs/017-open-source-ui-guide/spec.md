# 开源UI实践指南

## 用户与核心路径

- US1（P1）：读者沿现有beui-motion-lab地址打开新版中文文章，从灵感、整页、区块、组件、原语、规范选择材料，同页放大并实际操作；关闭后回到原位置。
- US2（P1）：读者选定借什么、放哪里、怎么改，组合任务，复制对应源码或带来源的任务，交给自己的Agent；复制失败仍可手动取得全部材料。
- US3（P2）：读者在当前浏览器并排查看自己的参考图与结果图，记录差异并复制修正要求；文件不上传。
- US4（P1）：维护者以用户提供的完整包为依据接入当前网站，核对来源和许可，完成同一实现的文档、自动检查、真实页面验证与上线。

## 功能要求与验收

- FR-001：保留原文章身份和站内操作，发布短开场、能力表和七个资源/验证章节；正式材料使用包内15项HyperUI/Open Props实现。SC-001：原地址、目录、搜索与返回路径工作，来源、节选和展示改动可核对。
- FR-002：资源墙支持按章节搜索、分类、大图切换、原位展开；预览支持前后项、手机宽度、适用的重播/暂停/参数对照。SC-002：桌面、320px及助手占位下无页面横溢；关闭与Escape恢复焦点，不触发文章换页。
- FR-003：只执行经过审阅的固定本地预览，保留不透明源沙盒、无网络/表单提交/顶层导航的边界；主站不放开任意内联脚本。SC-003：真实响应头下预览可用，模拟父页/外部消息不能控制预览，独立打开也有沙盒响应策略。
- FR-004：任务包含所选材料、版本、源码入口、取用范围和用户改动；代码复制附对应许可。SC-004：增删、重开编辑、复制失败和保存文本保持一致，不混入未选材料。
- FR-005：沿用既有助手入口，仅复制并打开，不改草稿或自动发送；保留手动粘贴提示。SC-005：真实宿主入口打开，自动复制失败时停留在可手选的任务文本。
- FR-006：比较图片仅在本地以对象URL展示，拒绝不支持格式和超过15MB的文件，替换/离页释放资源。SC-006：测试覆盖解码失败、替换和连续导航清理。
- FR-007：静态正文、图片和来源在无JS时可读；视频按需加载、离屏/离页暂停并尊重减少动态效果。SC-007：实际构建与浏览器检查证明，不复用独立包的完成声明。
- FR-008：现行功能、素材维护和发布说明随代码更新；旧beUI仍保留有效回归载体。SC-008：完整verify、budget、独立审查及线上同版本核验通过。

## 明确不做

不新建UI组件库，不扩大到SaaS能力复刻、可视化页面编辑、X视频采集、自动附加Paseo草稿、自动图片分析或公众投稿；不添加npm依赖，不改全站视觉风格，不把模板首屏节选称为完整模板。

## 端差异

中文原文更新；其他语言按真实发布状态处理，不伪造已审核译文。手机资源网格按实际容器宽度排列，复杂预览保持自身滚动。无JS保留静态材料及来源，选择/预览/比较为增强功能。自动设备模拟与真实iPhone验收分别记录。

## 行数预算

本规格目录不设行数硬上限。research记录固定预览的安全策略及宿主适配选择；无需额外数据模型、接口文档或快速开始副本。
