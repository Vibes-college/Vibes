# Great UI Scale 实施计划

## 技术决定与职责

- `src/features/great-ui/`承接已确认的React样板、内容、关系和实际路径；独立Vite入口由`scripts/great-ui*.ts`构建与预览，产物在被忽略的`.scratch/great-ui-dist`，保留本地入口；正式接入通过现有works路由按学习元数据选择模板。
- 复用项目已经安装的React、Motion、Tailwind、Lucide与Vite；不增加依赖或网络服务。原三件媒体和来源保持，少量实际路径组件按上游许可保留来源与适配记录，不导出组件库。
- 48条轻量目录与每件详细内容分离。目录用于筛选，详情和默认任务生成独立JSON/文本，浏览器按需加载并取消旧请求；字段缺失与失败显式反馈。
- 内容逐件核对固定源码及预览；三个栏目、Prompt和关系记录共用事实。能力字段将已知事实、适配要求、资源作用域及证据分开，目录描述不能当作运行证据。
- 编排器先筛角色与已知条件，再按稳定优先级扩展有界候选；每步最多8项，每轮保留6份方案，最多3份结果。整份方案检查任务覆盖、共享状态、时序与未知条件，保留省略和失败路径。
- 实际路径先实现作品集的异步换页、正文揭示和问答；转场覆盖、页面就绪与退出完成分别处理。再复用经过适配的能力完成产品介绍与任务工具路径，至少包含简化和负向验证。
- 每份验证绑定源码、能力、配置和规则摘要；变化使受影响结论待复核。作者提供视频可使用原始来源入口，不能为绕过限制复制或代理受限资源。作者视频返回429的11件，在公开原作页面实际操作并独立录制本地MP4，记录来源、操作与文件摘要；它们不是作者原视频的副本。

## 宪章检查与预算

用户批准48件站内学习接入；生产仍通过审阅与合并后的现有发布流程。沿用白底灰绿、视频优先、简介、自然排列标签和三栏；新增选择只服务作品检索与路径组合，不重新设计详情页。

新入口的预算覆盖入口压缩JS、CSS、目录和按需内容；媒体分开记账，不预加载48段视频。必须实际测量后设定与解释预算，不用放宽已有网站预算消化新内容。

## 验证与交付

- Node单元测试覆盖能力字段、来源/唯一性、硬冲突、未知条件、必需环节、固定项、有界候选、证据失效与复制材料；20个目标样本划分12个调整、8个保留检查。
- Playwright专用配置覆盖48件详情基本路径、搜索/切换/草稿、媒体失败、复制失败、实际组合、慢加载、重复操作、前进后退、键盘、窄屏与减少动态效果。由great-ui:verify单独运行，不并入整站verify。
- 内置浏览器逐件查看上游实际页面并记录观察；真实本地工作台操作、组合路径和布局另有证据。模拟设备与真机、合成负载与内容质量结论分开。
- 按真实接入与依赖范围运行本地great-ui:verify与相关检查器专项，完成本地入口预算和1,000/10,000合成负载。实际接入后运行正式站verify与budget，并复核整个PR最终SHA；此前本地验收不能代替站内验收。涉及外站失效时保留真实状态，不吞错或虚称完成。
- `docs/features/great-ui-learning.md`说明用户路径，`docs/features/project-commands.md`和受影响system说明维护命令、资料与验证；源码说明复核后更新摘要。

## 浏览范围与顺序

- browsing.ts负责范围、随机顺序和实际浏览记录；按类别分桶打乱，逐步优先不同类别，无重复抽签重试。普通顺序按目录排列，上一件始终使用真实记录；显式选作品可重访已看内容，自动随机不重抽已看作品。
- CaseNavigation保留原弹窗，分类与搜索作为选择草稿，选中作品后才提交范围；Taxonomy标出当前作品分类。随机按钮只改变后续顺序，尾部入口由用户重开一轮。两种入口复用同一规则，不增依赖、服务或URL参数。
- browse-storage保留页面history快照与sessionStorage记录，localStorage只保存范围和模式。新页面采用目标会话，浏览器返回优先恢复该页快照，保留Astro历史字段；存储失败时当前访问使用内存。useCaseBrowser隔离副作用并防止重复切换，LearningPage返回导航结果以恢复失败状态。
- 本增量遵照已确认的回归豁免，执行纯规则与存储契约测试、check、两种构建/预算及静态产物核对，不重跑浏览器与独立审查；T024–T025仍保留完整验收待办。

## 可切换合集与清晰录屏

- 从已发布成员的collectionId投影合集封面，合集卡片所在的有限分页随HTML携带轻量索引，DOM只包含当前预览；沿用media根节点、200ms可见停留、1/2个播放上限、手动独占、离屏和生命周期清理。索引仅含作品ID、标题和轻量素材信息，单合集gzip小于6KiB；切换时替换当前媒体节点，不预载成员视频；与目录/搜索/详情共用安全渲染和来源校验。
- 页面级普通JS和媒体JS继续遵守既有预算。组合示例复用Motion的轻量react-m入口和domAnimation，不携带未使用的布局/拖动特性；共享流式读取约束去除媒体加载器重复代码。媒体清单和高清版本独立计量；网络检查确认无合集页面不请求合集数据，离屏不请求其视频，点击下一件只加载下一件。空闲加载仅用于小型交互准备，不用于自动获取高清素材。
- learning.media维护桌面、手机和轻量封面的路径与实际像素，原始捕获和转码摘要同步local-recordings。播放器按设备选一份素材，首屏不同时下载两端文件；窗口变化、高清查看保留播放位置和暂停意图。
- 放大用独立查看空间按可用视口适配实际视频比例，提供有效缩放/拖动和退出；保留背景隔离、键盘与焦点恢复。在页面内全屏使用完整视口；手机横向素材默认1.5倍，避免外框扩大而内容几乎不变，支持重置为完整画面。
- 先完成三类两端样本及封面网络、播放、有效放大验收，随后逐件扩展48件；保留原动作与时间线。预算按实际产物制定有界媒体约束，不增加服务或依赖，不提高普通页面资源上限。
