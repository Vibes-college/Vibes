# Great UI 全量学习与组合工作台

## 用户与核心路径

- US1（P1）：普通用户在现有样板中浏览、搜索并切换Great UI的48个登记作品，观看实际预览，阅读中文简介和拆解，查看来源与许可；手机保持可读且失败时有可继续的入口。
- US2（P1）：用户说明使用位置并选择修改目标，取得包含固定来源、原作行为、改造理由、限制与检查的任务，交给自己的Agent；页面与任务使用同一份内容。
- US3（P1）：用户从当前作品选择完整操作路径，查看有分工、替代、适配条件与冲突原因的组合方案；实际体验经过接入验证的路径，再生成相同材料的组合任务。
- US4（P1）：维护者按唯一ID和固定版本核对、扩充内容；能够区分目录登记、源码核对、实际操作和组合验证，更新时只使依赖变化的证据失效。

## 功能要求与验收

- FR-001：全量范围固定为上游`eda1b85ed81ab45d0f0cbc27dc0206560d11c801`登记的48件、7类，保留已确认的三例内容和界面。SC-001：48个唯一入口有中文详情、可定位来源、拆解、目标驱动改造、关系入口和任务；已有URL保持工作。
- FR-002：保留先看效果、简介、`by Great UI`、按内容宽度排列的分类和独立许可行，以及「拆解设计/改造设计/串联设计」三栏。SC-002：320px、常规手机和桌面无横向溢出，切换案例、前进后退、草稿、弹层、失败反馈可操作。
- FR-003：作品能力记录包含角色、前置条件、触发与可观察结果、影响范围、适配与冲突、来源和证据。SC-003：关键事实能追到固定源码或真实操作；未知、建议与已验证分别标记；变体不重复计数。
- FR-004：根据用户路径和条件筛选候选并检查整份方案；支持替代、原理联系、冲突与可选效果，不强制填满。SC-004：硬冲突不能被评分覆盖，未知条件显示适配待办，无法满足的必需环节明确说明，候选和方案数量有界。
- FR-005：至少完成三条不同目标的实际路径，包含现有三例的真实交接、简化方案和必要适配；组合材料与实际实现相符。SC-005：真实操作、异常加载、重复导航、键盘、窄屏和减少动态效果有证据；转场换页时机不冒充退出完成。
- FR-006：检索目录和详情按需加载，当前作品MP4打开即静音播放；不增加启动卡片、媒体提示行或预载其他作品，静态预览直接显示，异常提供原作入口；复制失败保留全部任务。SC-006：20个需求评估样本区分调参与保留检查；已知硬冲突漏报为0、未知和适配完整披露，合成1,000/10,000条负载只用于性能结论。
- FR-007：维护命令校验来源、唯一性、内容完整性、引用与版本依赖，生成页面与Agent材料。SC-007：来源或配置变化能使依赖证据待复核；重复运行不制造重复记录；缺失材料不会虚报验证。
- FR-008：独立本地构建，复用现有依赖和当前预览地址；源代码、维护说明和验证同批交付。SC-008：必要检查、资源预算、内置浏览器与独立审查通过；提供可查看的Draft PR及进度，未合并、未部署分别明示。

## 明确不做

本阶段不发布网站、不替换线上文章、不继续旧017的文章接入，不新增npm依赖、账号、在线数据库、自动调用项目Agent或公众编辑。不保证任意组合最优，不把未实测参数称为最佳；不绕过上游访问限制，不批量转售或再分发上游组件库。

48件主要交付原创中文拆解、改造与关系材料、原作/固定源码链接及有来源的预览。用于实际路径的少量组件适配属于本地应用实现，保留许可与改动说明；作者视频或其他素材的可访问不等于再发布授权，缺权利证据时不将其打包公开。

## 端差异与实施顺序

先验证三例实际组合，再扩到覆盖7类、替代、全局状态及外部数据的12件，最后48件。单件外部不可用只阻塞其依赖证据，其他工作继续；记录真实缺口，不以其他作品替补数量。

手机与桌面共用布局和数据；无JS提供说明和原作链接。自动模拟与真实手机分别记载。网络、复制或媒体失败有可见退路，少动态偏好保持操作和内容可见。
