# Great UI 全量学习与组合工作台

## 用户与核心路径

- US1（P1）：普通用户在现有样板中浏览、搜索并切换Great UI的48个登记作品，观看实际预览，阅读中文简介和拆解，查看来源与许可；手机保持可读且失败时有可继续的入口。
- US2（P1）：用户说明使用位置并选择修改目标，取得包含固定来源、原作行为、改造理由、限制与检查的任务，交给自己的Agent；页面与任务使用同一份内容。
- US3（P1）：用户从当前作品选择完整操作路径，查看有分工、替代、适配条件与冲突原因的组合方案；实际体验经过接入验证的路径，再生成相同材料的组合任务。
- US4（P1）：维护者按唯一ID和固定版本核对、扩充内容；能够区分目录登记、源码核对、实际操作和组合验证，更新时只使依赖变化的证据失效。

## 功能要求与验收

- FR-001：全量范围固定为上游`eda1b85ed81ab45d0f0cbc27dc0206560d11c801`登记的48件、7类，保留已确认的三例内容和界面。SC-001：48个唯一入口有中文详情、可定位来源、拆解、目标驱动改造、关系入口和任务；已有URL保持工作。
- FR-002：保留先看效果、简介、`by Great UI`、按内容宽度排列的分类和独立许可行，以及「拆解设计/改造设计/串联设计」三栏。SC-002：320px、常规手机和桌面无横向溢出，切换案例、前进后退、草稿、弹层、失败反馈可操作。
- FR-003：作品能力记录包含角色、前置条件、触发与可观察结果、影响范围、适配与冲突、来源和证据。SC-003：关键事实能追到固定源码或真实操作；未知、建议与已验证分别标记；变体不重复计数。
- FR-004：根据用户路径和条件筛选候选并检查整份方案；支持替代、原理联系、冲突与可选效果，不强制填满。SC-004：硬冲突不能被评分覆盖，未知条件显示适配待办，无法满足的必需环节明确说明，候选和方案数量有界。
- FR-005：至少完成三条不同目标的实际路径，包含现有三例的真实交接、简化方案和必要适配；组合材料与实际实现相符。SC-005：真实操作、异常加载、重复导航、键盘、窄屏和减少动态效果有证据；转场换页时机不冒充退出完成。
- FR-006：检索目录和详情按需加载，当前作品MP4打开即静音播放；不增加启动卡片、媒体提示行或预载其他作品，静态预览直接显示，异常提供原作入口；复制失败保留全部任务。SC-006：20个需求评估样本区分调参与保留检查；已知硬冲突漏报为0、未知和适配完整披露，合成1,000/10,000条负载只用于性能结论。
- FR-007：维护命令校验来源、唯一性、内容完整性、引用与版本依赖，生成页面与Agent材料。SC-007：来源或配置变化能使依赖证据待复核；重复运行不制造重复记录；缺失材料不会虚报验证。
- FR-008：独立本地构建，复用现有依赖和当前预览地址；源代码、维护说明和验证同批交付。SC-008：必要检查、资源预算、内置浏览器与独立审查通过；提供可查看的Draft PR及进度，未合并、未部署分别明示。

- FR-009：每件作品使用现有works稳定路由和学习详情模板；Explore先展示一件合集，合集与搜索可找到48件，普通文章保持原有阅读路径。SC-009：直接打开、刷新、站内往返、关联作品、无效地址、canonical和语言缺失状态正确；中文材料不伪装为英文译文。
- FR-010：每件每语言一份Markdown维护拆解、改造与串联说明；目标、验收、术语引用与案例说明同文件维护，通用术语解释来自共享词库，来源与媒体等作品共享字段在work.json。SC-010：修改一件内容后页面与Agent文本/JSON同步，错误字段或缺少分区构建失败；GitHub编辑入口指向实际文件，静态HTML保留可读正文和搜索材料。
- FR-011：核心预览使用本站维护的文件和海报，保留真实来源、捕获方法及许可范围。SC-011：48件核心预览不请求作者媒体地址，实际解码/播放与静态图逐件核对；正常打开即播放，失败/少动态偏好可继续；线上任务含可访问的绝对媒体地址，不混入本机路径。
- FR-012：三条可操作示例及组合任务在正式站可用；独立命名内容/媒体地址并隔离样式，沿用现有站点页面上下文。SC-012：普通文章不载入学习交互脚本或受其样式影响；正式站新路由、搜索、GitHub编辑、媒体、任务与三条示例通过本地验证与独立审查，用户合并前不部署生产。
- FR-013：维护共享UI/UX术语Markdown词库，沿用用户提供文章的工具、触发、动效和UX规则分类及解释、变体、适用场景、提示词编排；完整保存原文及出处，区分原文与Vibes整理。作品引用稳定词条ID，只维护本例应用、参数与判断。SC-013：48件现有术语全部接入共享解释，同义词合并；缺失引用、重复ID或别名冲突拒绝构建。共享解释修改同步页面与两种任务，并使相关内容修订和组合证据待复核；提供词库索引及收录模板。

- FR-014：浏览范围与随机顺序独立选择。保留四宫格进入的作品弹窗，标题为“浏览作品”；入口显示全部分类或选定分类，旁边以小底色图标切换顺序/随机；数量仅在右侧进度显示。分类在选择作品后应用，搜索只筛弹窗列表。首次默认为全部分类和随机，当前作品的真实分类在标签中另列。SC-014：范围内随机一轮不重复，全部分类时优先换类；上一件返回实际看过的作品，退回后再前进复用原顺序。切换随机保持当前作品和返回记录，从下一件生效；一轮结束后由用户开始新一轮。范围、顺序与会话记录支持跨页、刷新和浏览器返回，损坏/不可用存储安全回退；单件范围不跳出，显式进入范围外作品切回全部分类。

- FR-015：Explore和合集详情首屏用内部作品作为可切换封面，显示合集身份、数量和当前作品名称；可切换预览并进入当前作品，合集标题仍进入合集。复用当前媒体播放调度，不在首页安装React学习工作台。SC-015：首屏不取全量录屏、高清文件或隐藏成员海报；只在可见停留或主动操作后播放当前短片，手机最多1个、桌面最多2个自动播放。切换释放旧视频，离屏/后台/分页/搜索替换停止，省流量与减少动态偏好保留手动播放；键盘、触摸和无JS入口可用，普通首页预算不放宽。
- FR-016：录屏按作品实际内容取景，桌面与手机分别使用适合其排版的素材；页面或文字类保留完整关键动作，局部组件去掉无关空白。放大须实质提高有效内容尺寸，支持缩放和移动，退出恢复进度与焦点；在页面视口内全屏查看，不依赖原生Fullscreen API。SC-016：以社交卡片、滚动文字、页面转场先验证两端样板，再逐件处理48件；保存原始帧、时间线、裁切和编码来源及摘要。实际检查文字可读性、动作未裁断、放大前后内容尺寸、真实播放和按需请求，不以HTTP成功、按钮变色或模拟设备代替真机。

## 明确不做

本阶段完成正式站接入和可供合并的交付，不继续旧017的文章接入，不新增npm依赖、账号、在线数据库、自动调用项目Agent或公众编辑。不保证任意组合最优，不把未实测参数称为最佳；不绕过上游访问限制，不批量转售或再分发上游组件库。

48件主要交付原创中文拆解、改造与关系材料、原作/固定源码链接及有来源的预览。用于实际路径的少量组件适配属于本地应用实现，保留许可与改动说明；作者视频或其他素材的可访问不等于再发布授权，缺权利证据时不将其打包公开。

## 端差异与实施顺序

本地三例、12件和48件已完成；正式站先以一件Markdown跑通内容编辑、详情、任务和媒体路径，再迁移48件与三条示例。单件外部不可用只阻塞其依赖证据，其他工作继续；记录真实缺口，不以其他作品替补数量。

手机与桌面共用布局和数据；无JS提供说明和原作链接。自动模拟与真实手机分别记载。网络、复制或媒体失败有可见退路，少动态偏好保持操作和内容可见。

媒体改善先以LinkedIn职业资料卡、滚动文字揭示、错峰页面转场完成合集封面、有效放大和两端素材的整条路径；检查成立后扩展其余45件。维护轻量封面与详情素材的明确分工，不能靠首页空闲时下载全量视频来换取切换速度。
