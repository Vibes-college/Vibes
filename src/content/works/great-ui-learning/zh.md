## 从作品开始

- [错峰页面转场](/zh/works/great-ui-staggered-page-transition/) — 把一次页面切换拆成一组有先后顺序的动作，让旧内容退场、新内容出现得更从容。
- [折叠问答](/zh/works/great-ui-accordion/) — 先露出问题，再按需展开答案。一次只打开一项，让密集信息保持清楚的阅读顺序。
- [滚动文字揭示](/zh/works/great-ui-text-reveal/) — 用滚动进度点亮文字：从模糊的底稿经过一瞬强调色，再落到清晰正文，阅读节奏由手指决定。
- [路径描画标志](/zh/works/great-ui-animated-path/) — 让标志的线条依次出现，再逐渐填色，把静态图形变成一段可读的形成过程。
- [分步状态清单](/zh/works/great-ui-deployment-checklist/) — 把一项长任务拆成清楚的步骤，让用户看到哪一步正在运行、已经完成或需要处理。
- [有层级的基础按钮](/zh/works/great-ui-button/) — 用同一套尺寸、形状和状态表达主操作、次操作与不可操作，让用户容易判断下一步。
- [GitHub 贡献悬浮卡](/zh/works/great-ui-github-card/) — 鼠标停在 GitHub 链接上时展开资料卡，用小格子呈现近期贡献，让个人链接带上更多背景。
- [分割展开主题](/zh/works/great-ui-split-theme-provider/) — 让新主题从中央展开，或让旧主题向中央收拢，把明暗切换表现为一次有方向的揭示。
- [手机里的对话演示](/zh/works/great-ui-mobile-mockup/) — 把一段预设对话放进手机外壳，按节奏显示消息和正在输入的提示，帮助访客理解产品场景。
- [随滚动飞入的卡片](/zh/works/great-ui-scroll-flying-cards/) — 每张卡片随滚动进入、停留和离开，背景文字保持在视野中，让几个重点形成连续的阅读段落。
- [彩色边缘页面转场](/zh/works/great-ui-color-wipe-page-transition/) — 用带彩色边缘的分块遮挡完成页面切换，让移动方向和节奏更鲜明。
- [悬停人物名单](/zh/works/great-ui-team-section/) — 把人物姓名排成清晰名单，鼠标经过时显示职位和照片；窄屏直接展示人物卡片。
- [文字分行飞入](/zh/works/great-ui-split-line-fly-in/) — 一段文字按行从两侧进入，逐渐收拢字距并变清晰，把阅读展开成有方向的节奏。
- [滚动文字由模糊到清晰](/zh/works/great-ui-blur-scroll-reveal/) — 把段落拆成词或行，随滚动依次提高可见度、减少模糊，让文字逐段进入阅读状态。
- [词语逐个聚焦](/zh/works/great-ui-word-focus-scroll/) — 词语随滚动从较小、模糊和透明变为正常大小，用连续的聚焦过程强调阅读顺序。
- [沿曲线滚动的文字](/zh/works/great-ui-text-on-path-scroll/) — 让文字贴着一条曲线移动，用滚动推动文字经过画面，形成一段有空间感的排版。
- [扰动字形的命令切换](/zh/works/great-ui-scrambled-install-command/) — 切换安装方式时，让命令中的字符短暂变化再还原，用局部动态强调文字已经更新。
- [多语言引语切换](/zh/works/great-ui-multilingual-quote/) — 在同一位置切换不同语言的短句，用轻微模糊和位移连接文本变化，同时保留作者信息。
- [双帘开合转场](/zh/works/great-ui-curtain-page-transition/) — 两块遮罩从相对的两边合到中央，再退回两侧，把内容切换放进短暂闭合的时刻。
- [交错插入转场](/zh/works/great-ui-interlocking-page-transition/) — 相邻条带从相反方向进入，像彼此咬合的梳齿一样覆盖旧内容，再继续离开。
- [多层扫过转场](/zh/works/great-ui-sweep-page-transition/) — 数块整屏色层依次扫过，让颜色形成前后层次，再露出下一份内容。
- [像素格溶解转场](/zh/works/great-ui-pixel-page-transition/) — 小方格以打散顺序变得不透明，覆盖画面后再消失，用颗粒感连接两份内容。
- [波浪节奏转场](/zh/works/great-ui-sine-wave-page-transition/) — 长条仍沿直线移动，但出发时间按波形排列，让覆盖边缘呈现高低起伏。
- [对称阶梯转场](/zh/works/great-ui-cascade-page-transition/) — 条带从中央向两边或从两边向中央依次移动，用对称的阶梯轮廓覆盖页面。
- [百叶条带转场](/zh/works/great-ui-venetian-blinds-page-transition/) — 一排细长条逐渐变宽或变高，盖住画面后再收细，形成百叶式开合。
- [交叉模糊转场](/zh/works/great-ui-cross-blur-page-transition/) — 整幅画面短暂变模糊，再从模糊中恢复为新内容，用较柔和的变化连接两页。
- [沿方向扫开的主题](/zh/works/great-ui-swipe-theme-change/) — 新主题从选定边缘或角落铺开，页面布局保持原位，用一条移动边界解释明暗变化。
- [从一点展开的主题](/zh/works/great-ui-circular-theme-provider/) — 让新主题从按钮、角落或指定点形成圆形扩散，将状态变化与触发位置联系起来。
- [模糊淡化的主题切换](/zh/works/great-ui-blur-fade-theme-transition/) — 旧主题渐渐模糊淡出，新主题同时从模糊中变清晰，适合不强调方向的短暂切换。
- [LinkedIn 职业资料卡](/zh/works/great-ui-linkedin-card/) — 把职业简介放在LinkedIn链接上方，悬停时补充头像、职位、地点与人脉数。
- [Facebook 人物资料卡](/zh/works/great-ui-facebook-card/) — 悬停Facebook链接时展开封面、头像和简介，让外部个人链接更容易辨认。
- [Instagram 账号资料卡](/zh/works/great-ui-instagram-card/) — 在Instagram链接旁补充头像、简介和三组账号数量，让外链有简明的视觉预览。
- [X 账号悬浮资料卡](/zh/works/great-ui-twitter-card/) — 鼠标停在X链接上方时展示资料卡，也能改成常驻卡片，给作者链接补充背景。
- [黏连展开的圆形菜单](/zh/works/great-ui-radial-gooey-menu/) — 点击中心按钮，几个图标向四周散开；圆之间的黏连效果让展开过程显得连续。
- [展开设置的浮动工具条](/zh/works/great-ui-floating-dock-menu/) — 一排分类按钮按需向上展开设置，切换分类时容器跟随内容变化，让常用配置集中在手边。
- [展开成面板的浮动导航](/zh/works/great-ui-floating-menu/) — 顶部短栏展开为分组导航面板，让主要链接、辅助入口和社交链接按层级出现。
- [有细节反馈的文字链接](/zh/works/great-ui-animated-link/) — 让链接在悬停时通过线条、文字填色或替换强调可点击性，保留正文式的轻量外观。
- [字符轨迹等待动画](/zh/works/great-ui-terminal-loader/) — 一块色条在等宽字符间来回移动，尾部留下逐渐变淡的字符，营造终端风格的等待感。
- [按方向揭开的图片](/zh/works/great-ui-image-hover-reveal/) — 从灰度底图中揭开彩色图或另一张图，鼠标进入方向决定揭示从哪边开始。
- [从图像变成字符画](/zh/works/great-ui-pixel-to-ascii-image/) — 悬停图片时，画面先变为色块，再由亮度对应的字符重组，离开时恢复原图。
- [笔记本里的对话演示](/zh/works/great-ui-macbook-mockup/) — 用笔记本外壳和左右分栏呈现一段预设对话，帮助访客想象桌面产品的使用场景。
- [滑出唱片的专辑卡](/zh/works/great-ui-vinyl-album-card/) — 鼠标经过专辑封面时，唱片向右滑出并旋转，封面轻微倾斜，把平面图片变成可感知的物件。
- [带姓名提示的头像叠放](/zh/works/great-ui-avatar-stack/) — 把少量人物头像叠成紧凑一组，悬停时抬起当前头像并出现姓名，表达参与者关系。
- [斜向循环图片墙](/zh/works/great-ui-diagonal-marquee-carousel/) — 多排图片沿斜向持续流动，相邻排可以反向，让静态封面形成有层次的背景。
- [按日期浏览的修订时间轴](/zh/works/great-ui-revision-timeline/) — 点击日期刻度或前后按钮切换一份记录，当前日期居中，附近刻度升高帮助定位。
- [有分隔线反馈的图片卡](/zh/works/great-ui-card/) — 图片下方放标题和日期，鼠标经过时中间分隔线从左向右变深，给内容块轻微回应。
- [轻量立体按钮](/zh/works/great-ui-minimal-buttons/) — 用细边框和内阴影形成轻微厚度，五种视觉层级共用同一组尺寸。
- [带内发光的按钮](/zh/works/great-ui-aceternity-button/) — 用渐变、内阴影和环线形成较明显的按钮层次，按下时轻微缩小。

## 如何使用

先看演示，在「拆解设计」理解行为与限制；到「改造设计」选择目标并生成任务，或用「串联设计」选择完整操作路径。

说明由 Vibes 编写，来源链接保留到固定版本源码。原作采用自定义许可，允许在应用和网站使用，限制整库再分发。复制任务不代表已在你的项目完成接入。
