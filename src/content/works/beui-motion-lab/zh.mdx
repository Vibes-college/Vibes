## 开始

AI 做 UI，常卡在三处：没懂你想要什么、没把效果做准、做完没检查。给它看参考，用现成代码，再对着结果改。

| 能力 | 传统重心     | AI 原生重心 |
| ---- | ------------ | ----------- |
| 视觉 | 绘制、排版   | 比较、取舍  |
| 表达 | 设计稿、标注 | 参照、差异  |
| 实现 | 手写、封装   | 选材、组合  |
| 动效 | 编写、调参   | 选样、调参  |
| 交付 | 测试、修复   | 验收、纠偏  |

**有开源实现，就先拿来用。** Vibes 把效果、源码和大白话对齐；你挑喜欢的，Agent 负责接进项目。

## 原语

原语是更基础的零件：负责选中、展开、移动，不替你决定整个界面的长相。这里直接试浏览器控件与开源动画，不必先背名字。

## 规范

好组件拼在一起，也要统一字体、颜色和间距。Tokens 就是共享的设计参数；先调一项看差别，再让 Agent 对齐现有规范。

### 取用

每项保留作者、许可、源码版本和展示改动。模板节选不是完整页面，演示通过也不等于你的项目已经可用。

选择“借什么、放哪里、怎么改”，任务会带上对应源码。“复制并打开助手”不会自动发送；进入自己的项目，粘贴后执行。
