# 物件隐喻 / Object metaphor

借用现实物体的层次和动作，让数字内容的组织方式更直观。

## 常见变体

唱片、卡片、文件夹等现实物体的视觉借喻。

## 适合用在哪里

帮助理解数字内容组织与状态。

## 什么时候不用

外观像播放器不等于有播放能力；隐喻不能造成错误期待。

## 提示词例子

```text
借唱片层次展示专辑，若没有播放能力就不要使用会误导的播放入口。
```
