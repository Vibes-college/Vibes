# 用户体验 / UX

UX 是 User Experience 的缩写，中文叫“用户体验”。它关注页面用起来是否顺畅：用户能不能看出哪里可点，操作后有没有反馈，键盘和手机能不能正常使用，动画会不会干扰阅读或引起眩晕。

## 常见变体

Vibes整理：操作路径、反馈、可访问性和阅读体验。

## 适合用在哪里

Vibes整理：从开始到完成检查用户是否能顺利完成一件事。

## 什么时候不用

Vibes补充：不能用页面好看代替实际操作和失败路径的验证。

## 提示词例子

```text
请按用户完成任务的顺序检查入口、操作反馈、异常恢复、键盘和手机使用。
```
