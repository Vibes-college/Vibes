# 用自然语言描述网页 / Vibe coding

Vibe coding 是用自然语言描述页面、行为和功能，让 AI 生成、修改并调试代码。描述越具体，AI 越容易做出你脑中的画面。

## 常见变体

Vibes整理：页面、行为、功能与调试要求。

## 适合用在哪里

Vibes整理：把预期的画面和操作写成可执行描述。

## 什么时候不用

Vibes补充：只说高级、丝滑或有科技感，无法明确触发方式与完成状态。

## 提示词例子

```text
先检查项目已有结构，再实现标题按行显现、卡片依次进入，并说明如何验证。
```
