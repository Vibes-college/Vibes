# 演示状态 / Demonstration state

由预设内容和时间驱动的展示状态，用于解释流程，不等于真实服务正在运行。

## 常见变体

预设序列、可点击演示、循环演示。

## 适合用在哪里

功能说明、概念展示和产品介绍。

## 什么时候不用

演示状态不能声称真实请求、支付、加密或服务已完成。

## 提示词例子

```text
用预设序列展示消息流程，并明确标为演示；移除没有真实动作的误导性按钮。
```
