# 悬浮资料 / Hover profile

在主链接附近按需展示补充背景，减少跳转前的不确定性。

## 常见变体

指针悬浮资料、聚焦资料、点击展开资料。

## 适合用在哪里

链接旁的补充简介和身份信息。

## 什么时候不用

关键资料不能仅对鼠标用户开放；浮层不能溢出可视区域。

## 提示词例子

```text
在资料链接附近按需显示简介，键盘聚焦和触屏点击也可打开；根据边缘调整位置。
```
