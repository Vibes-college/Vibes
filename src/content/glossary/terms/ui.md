# 用户界面 / UI

按钮、卡片、导航栏、输入框、弹窗、图标、颜色、字体和页面布局，都属于 UI。

## 常见变体

Vibes整理：视觉、控件与页面布局。

## 适合用在哪里

Vibes整理：说明页面由哪些可见元素组成。

## 什么时候不用

Vibes补充：不要只描述颜色和外观就当作用户已经能顺利完成任务。

```text
请列出页面的主要控件和信息层级，再说明每个控件的交互状态。
```
