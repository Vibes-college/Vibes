## 不用先写代码，也能观察一个模型怎样学习

Teachable Machine 是 Google 提供的交互式机器学习工具，可以围绕图像、声音或姿态等材料尝试分类。它把收集样本、训练和试用放在较容易进入的流程里。这个入口的价值是让人看见数据与结果的关系，而不是消除所有机器学习难题。 [查看来源](https://teachablemachine.withgoogle.com/)

## 训练时的背景也可能被学进去

如果第一类照片总在白墙前，第二类总在书架前，分类结果可能依赖背景而不是你想识别的物体。这是编辑提出的实验情境，用来帮助理解数据偏差。试用时有意识地改变环境，往往比继续增加相似样本更有启发。

### 三个值得观察的角度

下面是 Vibes 的阅读提示，用来组织问题与比较材料。

| 观察角度 | 先问什么             | 阅读时留意             |
| -------- | -------------------- | ---------------------- |
| 样本收集 | 各类材料有什么共同点 | 避免无关背景与标签绑定 |
| 训练     | 模型使用哪些例子     | 保持验证材料独立       |
| 试用     | 新条件下是否仍有效   | 改变角度、光线和背景   |

## 带着一个小练习继续探索

用两个容易区分的物体创建小实验。训练结束后，换一个拍摄地点，再试一次。如果效果下降，回看样本中是否有重复的环境线索。整个练习的目标是形成检查习惯，不是把小演示直接升级为可靠的生产系统。

### 把阅读变成自己的判断

1. **先理解材料。** 用自己的话解释作品要解决的问题，保留你尚未理解的概念。
2. **再记录观察。** 把亲眼看到的结果与自己的推测分开，写下形成判断时的条件。
3. **回到原始来源。** 遇到影响结论的细节，继续阅读原文、文档或完整节目，不只依赖这份导览。

> 阅读笔记：有价值的探索，既包括发现新的可能，也包括知道一个结论适用于什么条件。
